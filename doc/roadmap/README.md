# Roadmap

Planned milestones and feature directions for the Paperback Reading Tracker.

---

## Planned Milestones

### v1.8.0 — Catalog Search & Discovery
* **Open Library Integration**: Search by title, author, or ISBN to auto-populate metadata and cover images.
* **Format Switchers**: Dedicated filters for Web Novels, Light Novels, and Traditional Fiction.
* **Quick Library Add**: One-click addition to *Plan to Read* or *Reading*.

---

### v1.9.0 — Analytics & Visualization
* **Reading Heatmaps**: Matrix of daily reading activity and session frequency.
* **Genre & Format Distribution**: Breakdown of reading habits across tags and publication types.
* **Completion Forecasting**: Dynamic completion date estimates based on reading velocity.

---

### v2.0.0 — Multi-Profile & Cloud Export
* **Multi-Profile Support**: Independent reading libraries and goals per user account.
* **Encrypted Cloud Backups**: Direct encrypted backups to personal storage providers.
* **Third-Party Imports**: Automated migrations from Goodreads, StoryGraph, and Hardcover.
